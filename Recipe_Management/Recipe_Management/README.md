# Ghar Ka Swad

A recipe collection for traditional Indian favourites, from masala dosa and poha to Punjabi chole, biryani, samosas and gulab jamun. Browse by meal, search ingredients, save favourites, and add your own recipes.

## Getting started

From this project folder, install dependencies and start the development server:

```sh
npm install
npm run dev
```

## Available commands

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run lint` checks the project with ESLint.
- `npm run preview` serves the production build locally.

Recipes and favorites are saved in the browser. User-added recipes are kept when the sample collection is updated.
