# Little Recipe Book

A small, responsive recipe manager built with React and Vite. Browse a starter collection, search and filter recipes, save favorites, and add or manage personal recipes.

## Run locally

```sh
npm install
npm run dev
```

## Features

- Browse recipes by category, search recipe details, and sort by preparation time.
- View ingredients and step-by-step instructions, check off ingredients, and print a recipe.
- Save favorites and create, edit, or delete your own recipes.
- Keep recipes and favorites between visits with browser local storage.

All app data is stored locally in the current browser. No account or server is required. Recipe photos and web fonts are loaded from external image/font providers.
